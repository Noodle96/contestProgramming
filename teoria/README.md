# Teoría

Notas teóricas que se van documentando a partir de los tópicos que aparecen al resolver problemas de programación competitiva. Un archivo por tópico; cada archivo se amplía con nuevas ideas/teoremas a medida que aparecen en problemas resueltos.

- [combinatoria.md](combinatoria.md) — combinatoria, teoría de permutaciones, conteo.
- binary-search.md — búsqueda binaria y binary search on answer (pendiente).
- dp.md — programación dinámica (pendiente).
- greedy.md — algoritmos voraces (pendiente).
- grafos.md — teoría de grafos (pendiente).
- estructuras-de-datos.md — BIT, segment tree, DSU, etc. (pendiente).
- matematicas.md — teoría de números, álgebra, etc. (pendiente).

## Formato de cada entrada

```
## Nombre del teorema/idea
**Problema relacionado:** [nombre](link)
**Enunciado:** ...
**Demostración / intuición:** ...
**Aplicación al problema:** ...
```

## Sección final obligatoria: Preguntas típicas de entrevistas

Cada archivo de tópico termina con una sección `## Preguntas típicas de entrevistas` (estilo Google/Amazon/Meta: "como buen CS student, ¿qué dirías...?"). Formato pregunta + respuesta breve, entre 5 y 8 preguntas por archivo — no una lista infinita, es para repaso rápido antes de una entrevista.

**Regla:** cada vez que se agregue una entrada nueva a un tópico, revisar si esta sección necesita una pregunta nueva o algún ajuste.
